CommuteScout

Live road conditions from 53 official agency feeds across 37 states: incidents, closures, chain controls, live traffic cameras, wildfire perimeters, and toll pricing. Also a public REST API and an MCP server.

commutescout.comWeb · API · MCP

FiberWatch

Type any US address and see every ISP that files coverage there, then get an email when something better arrives. Built on 49.1 million FCC records covering 2,067 providers.

getfiberwatch.com

OutageWatch

PG&E outage alerts with live restoration estimates, and plain-language answers instead of a utility status code.

/outagewatchiPhone · Android · Web

Chalkboard

Turns any topic into a narrated explainer video through a pipeline that drafts, fact-checks, animates, and renders it. Open source; the hosted version is in private beta.

chalkboard.studio
