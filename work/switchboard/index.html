Switchboard

One board for the Claude Code chats on all of your computers.

WhenOctober 2026 to now
Built withRust, GPUI, Python
Linksgithub.com/nicglazkov/switchboard

Why I built it

I run Claude Code on a desktop, a laptop and a server. Every chat lives in its own terminal on its own computer, and I kept losing track of which ones were waiting on me.

I wanted to see all of them in one place and answer the ones that were stuck. I also wanted to know what it would cost to pick an old one back up.

What it does

  • A board sorted by what each chat needs. Each computer gets a row, and its chats sit under Needs you, Working, Warm now, Gone cold or Quiet. You can answer a question right from its card.
  • What it costs to go back. A cold chat re-reads its whole history on the next message. Switchboard compares resuming it with starting fresh from a summary, and suggests whichever is cheaper.
  • Terminals from anywhere. You can open any chat's terminal in a tab or a window, even when that computer is behind another router.
  • New chats on any computer. You pick the computer, the folder and the model, or let it pick the computer for you.
  • Search and usage. It searches every chat on every computer, and it tracks plan usage against a daily budget.

How it works

  1. ServerRuns on one computer that stays on.
  2. HelperA small program on each computer where you use Claude Code.
  3. AppShows the board on Mac, Windows or Linux.
  4. No cloudEverything runs on your own computers, and there's no account to make.

What was hard

  • Mac, Windows and Linux

    The app is written in Rust with GPUI, and it runs on all three. The Mac build is signed and notarized, and the Windows build installs without admin rights.

  • Computers on different networks

    A laptop on one network has to open a terminal on a desktop that's behind another router. Everything goes through the server, so the two never have to reach each other directly.

  • Showing the cost

    Whether to resume a chat or start over is usually a guess. Switchboard works out both numbers, and it holds any message that would re-read a big cold chat until you confirm.
