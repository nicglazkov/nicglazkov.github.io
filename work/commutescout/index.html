CommuteScout

Live road conditions in 37 states, from 55 official feeds.

WhenJuly 2026 to now
Built withPython, FastAPI, Cloud Run, PostgreSQL, SwiftUI, Jetpack Compose
Linkscommutescout.comSource on GitHub

Why I built it

Before a long drive I want to check for closures, chain controls and fires along the way. All of that is public, but every state puts it out in its own format, and I wanted it all on one map.

I'd already made SABRE Plus, an Android plugin that adds five California feeds to another app. It got more than 1,100 downloads, and CommuteScout basically grew out of that.

What it does

  • The map and a route planner. You see incidents, closures, chain controls, cameras, wildfire perimeters and toll prices along your drive.
  • An API and an MCP server, so an AI assistant can answer questions about a drive. The MCP server is listed in the official MCP Registry.
  • Flare, an open protocol so other developers can add their own alert sources to the map.
  • Phone apps for iPhone and Android, written in SwiftUI and Jetpack Compose.

What was hard

  • Every feed is different

    Every agency has its own format and its own update schedule, and they don't even agree on what counts as a closure. Most of the work was getting all of that into one format without losing what each agency meant.

  • Checking the assistant's answers

    The code can pass every test and the assistant can still tell you something wrong about your drive. So I wrote 91 questions that have known answers, and I score the assistant on them against recorded feeds.

  • When a feed breaks

    Feeds change or go down with no warning. Every pull request runs more than 500 tests, and the service reports which sources are healthy.
